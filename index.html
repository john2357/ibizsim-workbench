多期推演（只读）

以当前台账为起点，把每一期的决策草稿、招聘试算、研发升级、机器购买和发债补现金连起来跑；只在本机计算，不会改决策单、不会提交模拟系统。

起点怎么选：默认从当前期初开始。若本期已经提交，请等模拟页面进入下一期、重新同步期初后，再把「起始期」设成下一期；不要把已提交期的旧决策当作推演起点。

机器规则：本期买 → 下期安装 → 再下一期才能用。发债上限 = 期初净资产×50% − 存量债券；债券比自动补足贷款便宜，但会持续付息。C/D 保底会挤占 A/B/C 的产能，默认 0；按本局参数，C 的每机时利润和份额都高于 D，过早给 D 保底通常会拉低综合分，建议等 P16 机器增加后让 D 自然进入。

怎么用推演结果

  1. 先点「对比买机方案」：一次跑不买/稳健/均衡/冲份额四套，先排除自动贷款或资金缺口，再看近似综合分、累计净利和期末份额。
  2. 再看「期末现金」和「自动贷款/债券」：现金贴着 250 万下限、自动贷款不为 0 的方案，先降机器购买或延后研发。
  3. 再看「市场份额」和「累计净利」：份额是 16 格平均，C/D 新品即使只做几十件也会抬高对应格子；但产能紧时 C 的每机时份额更高，别为了 D 把 C 砍太多。
  4. 机器购买看两期后的产能：本期买 40 台，要到再下一期才变成产量；别在本期现金已经很紧时一次性买满。
  5. 选定方案后，点「把首期方案填入决策单」，逐格核对价格、产量、研发、招聘、买机器和发债，再人工录入模拟页面。

四个标签分别看什么

  • 价格：每家公司、每个产品、每个市场的售价；本页自动算最低 / 中位 / 最高，显示我们相对全场的位置。
  • 分项指标排序：多家的综合分和资源规模；看我们第几名、对手工人 / 机器 / 债券。
  • 市场份额：每个产品 / 市场的销量占比；判断该守价还是抢量。
  • 主要指标：收入、利润、净资产等；和内部报表交叉核对。

粘贴市场消息

  1. 在模拟系统打开 报表 → 市场消息，用鼠标选中整张表（从「期数」到最后一行的「消息影响」），按 Ctrl+C。
  2. 粘贴到下面文本框；如果粘贴内容没有期数，把「起始期数」改成第一条对应的期数。
  3. 点「解析并保存」。程序会自动识别产品 A–D、市场 1–4、利好/利空和强弱。

识别规则是关键词启发式，不保证 100% 准确；保存后请对照原文扫一眼。中性/「无」的消息会保留，方便确认期数。

本期决策怎么用

  • 利好需求（尤其强）：别轻易降价；先保供货和广告，价格可守在全场中位或以上。供货不够就缺货，份额会丢。
  • 利空需求 / 低价进口冲击：谨慎扩产；价格别比全场中位高太多；必要时加促销或小幅降价，先保现金和份额。
  • 只影响某个市场：促销费优先给这个市场；别把全国四个市场一起降价。
  • 历史消息：已经反映在前几期结果里，不要拿第 1–8 期的消息当演示期的信号。等本期消息出来再调。

关于「制定战略」页：公开手册和七项评分里都没有这一页，多数队伍直接跳过、不填也不提交；真正决定成绩的是「制定决策」并提交决策单。如果你们赛区/规则明确要求填，就按草稿的相对位置快速选：草稿价低于全场中位→价格「低」，接近→「中」，高于→「高」；份额按目标，广告/促销按本期预算相对上期。不要把时间花在这页的精算上。

本地决策实验台 · 快速上手

这是一个完全离线的单文件工具：所有数据保存在本机浏览器，不发网络请求、不登录、不提交。

1. 准备期初

  1. 首次打开会载入内置的虚构演示数据，可以直接在「决策单」试用。
  2. 要换成自己的数据：在「期初」页逐项编辑，或用顶部「导入 JSON」导入兼容格式的本地文件。
  3. 「导出 JSON」可用于备份；导入/导出都只操作本机文件。

2. 做一期决策

  1. 进入「决策单」，按价格、广告、促销、供货、生产、研发、发展、财务的顺序填写 69 格。
  2. 看「三套方案对比」：保守 / 稳健 / 激进；点「填入决策单」只会改本机表单，不会提交到任何外部系统。
  3. 点「模拟」检查产能、原料、现金和粗略需求；红色警告先处理。
  4. 确认无误后，人工录入你所在的模拟系统。

3. 三套方案的含义

  • 保守：按弱需求处理，产量压到基准的 0.90，广告/促销降低，分红取净利 20%。
  • 稳健：基准草稿原样，分红取净利 50%。
  • 激进：按强需求重新排产，价格略降、广告/促销增加，分红取净利 70%；产能或现金不够时自动回退。

4. 合规提示

  • 本工具不是官方产品，不隶属任何模拟平台或赛事组织方。
  • 是否允许使用本地辅助工具，以你所在模拟环境的规则和规则要求为准。
  • 程序不会读取网页、不会自动填表、不会提交；所有最终操作都由你本人完成。

演示数据全部为虚构；模型中的需求弹性、广告/促销效果和成本估算都是粗略近似，不构成成绩预测。
