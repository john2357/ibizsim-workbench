# 数据与隐私

## 本地存储

- 应用状态保存在浏览器的 `localStorage`，键名为 `ibizsim-workbench-public-v1`。
- 清除浏览器站点数据会删除本机状态；请在清除前用「导出 JSON」备份。
- 同一个浏览器配置文件下的同源页面可以读取该键；公用电脑上使用后请清理浏览器数据。

## 网络

- 页面不加载外部脚本、字体、图片或分析服务。
- 不发起 `fetch`、`XMLHttpRequest`、`WebSocket` 或 `sendBeacon` 请求。
- 不包含遥测、埋点、账号或云同步功能。

## 导入 / 导出

- 「导出 JSON」由浏览器下载到本机。
- 「导入 JSON」只读取你手动选择的本地文件。
- 仓库内不包含任何真实比赛数据、队伍数据、账号、截图或个人信息。

## 演示数据

`demo/demo-state.json` 和 `index.html` 内置的演示状态全部为虚构数据，包括公司名“演示企业”、期初现金、库存、价格和决策值。它们不对应任何真实企业、队伍或比赛结果。

## 使用建议

- 不要把账号、密码、Cookie 或真实比赛数据提交到公开仓库。
- 在公用电脑上使用后，清理浏览器站点数据。
- 如需分享自己的状态，请先确认 JSON 中不含个人信息，再发送给可信对象。
