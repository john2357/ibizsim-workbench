# 模型与假设

本页说明 `index.html` 中本地模拟的近似逻辑。它不是官方规则，也不保证与任何模拟系统逐项一致。所有参数都可以在「参数（高级）」页修改。

## 1. 决策单

4×4 维度下共有 69 个决策字段：

- 4 产品 × 4 市场 = 16 个价格
- 4 个产品广告
- 4 个市场促销
- 16 个产品 / 市场供货
- 4 产品 × 4 班 = 16 个产量
- 4 个研发投入
- 招聘、辞退、买机器、买原料
- 银行贷款、债券、国债、分红、工资系数

2×2 维度下为 28 个字段，字段顺序与页面一致。

## 2. 需求估算

对每个产品 / 市场组合：

1. 以上期需求或上期销量作为需求基数；没有历史时使用期初市场容量 × 15%。
2. 若上期报价为 0，则按参考系数折回正常价格区间。
3. 用价格弹性调整需求：价格相对参考价越高，估算需求越低。
4. 叠加广告、促销、产品质量等级和消息面的方向性影响。
5. 情景方案可再乘一个需求因子（保守 0.90 / 稳健 1.00 / 激进 1.10）。

这是一个**方向性近似**：参数来自示例和经验，不包含真实竞争对手的反应函数。

## 3. 产能与供货

- 可用机器工时 = 机器台数 × 每台每班机时 × 班次数。
- 可用人工工时 = 工人数 × 正班工时 + 加班工时上限。
- 每个产品的产量不能超过对应机时和人工时约束。
- 新招聘工人本期只按一定比例形成产能；辞退和自然退休会减少可用工人。
- 可运出量 ≈ 产量 × 交付率 + 期初成品库存；供货超过可运出量会产生欠货 / 缺货警告。
- 原料采购量、原料可用率和期初原料共同约束生产。

## 4. 成本与现金

本地模拟按以下顺序估算：

1. 原料采购、原料运费和可能的批量折扣。
2. 工人工资、加班费、招聘 / 辞退安置费。
3. 机器折旧、维修费和管理费。
4. 成品运输固定费 + 变动费。
5. 广告费、促销费、研发费。
6. 库存费、废品损失。
7. 债券 / 银行贷款利息、税、分红。

现金低于最低现金时，页面会提示自动贷款或紧急贷款风险。三套方案的分红都会做安全钳制：

- 分红不超过本期净利；
- 期末现金不低于最低现金；
- 不允许通过自动贷款 / 紧急贷款来支付分红；
- 不满足时逐步下调分红，最低为 0。

## 5. 三套方案

三套方案共享同一份期初和同一套基准草稿，避免因为重新求解导致产品组合完全变形。

### 保守

- 需求因子 0.90；
- 产量固定压到基准的 0.90；
- 广告 / 促销 ×0.80；
- 分红取净利的 20%。

低产量会摊薄固定成本，因此保守方案的净利和现金**可能低于**稳健方案；它换来的是更低的成品积压和更小的经营规模。

### 稳健

- 需求 / 价格 / 广告 / 促销均按基准；
- 分红取净利的 50%。

### 激进

- 需求因子 1.10；
- 用强需求重新排产，并给基准中有产量的产品保留至少一半产量；
- 价格 ×0.98；
- 广告 / 促销 ×1.20；
- 分红取净利的 70%；
- 若产能、原料、现金或自动贷款检查不通过，自动回退到基准扰动版本。

## 6. 评分指标

页面可显示七项指标：本期利润、市场份额、累计分红、累计缴税、净资产、人均利润率、资本利润率。综合分权重可在参数页修改，默认仅用于本地对照，不代表官方计分。

## 7. 明确不包含

- 真实对手的定价反应和联盟行为；
- 随机事件、裁判临时规则、网络或提交异常；
- 官方需求公式、官方成本公式或官方评分实现；
- 任何自动登录、自动填表、自动提交能力。
