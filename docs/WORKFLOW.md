# 使用流程

## 1. 打开与准备

1. 双击 `index.html`，或运行本地静态服务器后打开页面。
2. 首次打开会载入虚构演示数据；要恢复演示状态，导入 `demo/demo-state.json`。
3. 在「期初（自动）」页核对或编辑现金、工人、机器、原料、库存、上期销量 / 价格 / 需求等。
4. 在「参数（高级）」页核对机时、人时、工资、税率、运费、最低现金等参数。

> 演示数据只用于熟悉界面。正式使用前，请把你所在模拟环境的真实规则和期初数据录入本机。

## 2. 填写决策

1. 进入「决策单（69格）」。
2. 可以手动逐格填写，也可以先看「建议 / 草稿」页的基准草稿。
3. 页面会自动检查明显问题，例如产量超过产能、原料不足、供货超过可运出量、现金不足等。

## 3. 对比三套方案

「决策单」页中部会显示：

- 保守：低产量、低广告 / 促销、低分红；
- 稳健：基准草稿；
- 激进：强需求重新排产、略降价、加广告 / 促销。

每张卡显示预计净利、期末现金、市场份额、营业收入、关键决策和风险提示。

点击「填入决策单」：

- 只覆盖本机决策单的 69 格；
- 不会写入任何网页表单；
- 不会向任何服务器发请求；
- 填入后仍建议点「模拟」并逐格核对。

三套方案是基于生成时快照的。手动改动决策后，卡片不会自动重算；需要时点「重算三套方案」。

## 4. 本地模拟

1. 进入「模拟（高级）」页，点「重新计算」。
2. 先看红色 / 橙色警告：产能、工人、机器、原料、供货、现金、自动贷款。
3. 再看净利、现金、份额和评分指标。
4. 调整决策后重复，直到没有硬约束问题。

## 5. 多期推演（可选）

「多期推演」页可以比较本期买 0 / 20 / 40 台机器、研发投入、发债等动作对后续几期的影响。推演结果是近似值，不包含对手变化和随机事件。

## 6. 保存与备份

- 「保存本期并带入下一期」会把当前期初、决策和模拟结果写入本机历史。
- 「导出 JSON」会下载完整本机状态；建议每期结束后备份。
- 换电脑时，在新机器上打开页面，用「导入 JSON」恢复。

## 7. 人工录入与提交

本工具到此为止。最终的价格、广告、促销、产量、招聘、买机器、贷款等字段，需要你本人在实际模拟系统中录入并提交。

- 本工具不登录、不读取网页、不自动点击、不提交。
- 提交前请再次核对参数、期初和规则。
- 是否允许使用本地辅助计算工具，以你所在环境的规则和工作人员要求为准。
